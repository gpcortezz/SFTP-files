1.1. Nombre del Proyecto:

SFTP Files

1.2. Descripción General:

SFTP Files es una aplicación web desarrollada en Flask que proporciona acceso a archivos a través de protocolo SFTP (SSH File Transfer Protocol) mediante una API REST. La aplicación permite la descarga de archivos comprimidos desde servidores SFTP remotos.

1.3. Visión General del Negocio/Dominio:

No especificado

1.4. Audiencia:

Desarrolladores que necesitan integrar funcionalidades de transferencia segura de archivos SFTP en sus aplicaciones, o usuarios que requieren acceso programático a archivos almacenados en servidores SFTP.
