5.1. Requisitos del Sistema:

  • Python 3.x
  • Pip (gestor de paquetes de Python)
  • Acceso a servidor SFTP para conexiones
  • Puertos necesarios: 5000 (Flask por defecto), 22 (SFTP)

5.2. Variables de Entorno:

No se encontraron variables de entorno específicas. La configuración se maneja mediante archivo config.json

5.3. Pasos de Instalación (Entorno de Desarrollo):

  1. Clonar el repositorio: git clone https://github.com/gpcortezz/SFTP-files.git
  2. Navegar al directorio: cd SFTP-files
  3. Instalar dependencias: pip install flask paramiko
  4. Configurar archivo config.json con credenciales SFTP
  5. Ejecutar la aplicación: python app.py

5.4. Pasos de Despliegue (Entorno de Producción):

  1. Preparar servidor con Python 3.x
  2. Instalar dependencias: pip install flask paramiko
  3. Configurar servidor web (nginx/apache) como proxy reverso
  4. Usar WSGI server (Gunicorn) para producción: gunicorn app:app
  5. Configurar servicio systemd para ejecución automática

5.5. Scripts de Ejecución Comunes:

  • python app.py - Ejecutar aplicación en desarrollo
  • gunicorn app:app - Ejecutar en producción con Gunicorn
