7.1. Visión General de la API:

La API desarrollada en el repositorio gpcortezz/SFTP-files es una aplicación Flask minimalista diseñada específicamente para servir archivos comprimidos a través de SFTP (SSH File Transfer Protocol). La API implementa un único endpoint dinámico que permite la descarga de archivos desde un servidor SFTP remoto.

Características principales:

  • Framework: Flask (Python)
  • Protocolo de transferencia: SFTP mediante la librería Paramiko
  • Autenticación: Basada en credenciales SFTP (usuario/contraseña)
  • Formato de archivos: Soporte para archivos comprimidos
  • Configuración: Externa mediante archivo config.json
  • Logging: Sistema de registro de errores en error.log

7.2. Lista Completa de Endpoints:

Método HTTP Ruta Descripción Autenticación Estado HTTP
GET /<compressed_file>/<filename> Descarga un archivo específico desde el servidor SFTP remoto Credenciales SFTP (configuración externa) 200 OK, 404 Not Found, 500 Internal Server Error

7.3. Detalle de Endpoints Clave:

Endpoint: GET /<compressed_file>/<filename>

Descripción:

Este endpoint permite descargar archivos específicos desde un servidor SFTP remoto. La ruta es dinámica y acepta dos parámetros que especifican el archivo comprimido y el nombre del archivo específico a descargar.

Parámetros de Entrada:

Parámetro Tipo Ubicación Obligatorio Descripción
compressed_file String Path Parameter Sí Nombre del archivo comprimido en el servidor SFTP remoto
filename String Path Parameter Sí Nombre específico del archivo dentro del archivo comprimido

Ejemplo de Request:

# Ejemplo usando curl
curl -X GET "http://localhost:5000/mi_archivo_comprimido.zip/documento.pdf"

# Ejemplo de URL completa
http://localhost:5000/backup_2024.zip/report.xlsx

Ejemplo de Respuesta (Éxito - 200 OK):

HTTP/1.1 200 OK
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="documento.pdf"
Content-Length: 1048576

[binary data del archivo]

Ejemplo de Respuesta (Error - 404 Not Found):

HTTP/1.1 404 Not Found
Content-Type: application/json

{
    "error": "Archivo no encontrado",
    "message": "El archivo 'documento.pdf' no existe en 'mi_archivo_comprimido.zip'",
    "status_code": 404
}

Ejemplo de Respuesta (Error - 500 Internal Server Error):

HTTP/1.1 500 Internal Server Error
Content-Type: application/json

{
    "error": "Error de conexión SFTP",
    "message": "No se pudo conectar al servidor SFTP remoto",
    "status_code": 500
}

Notas Adicionales:

  • La autenticación se maneja mediante credenciales SFTP configuradas en el archivo config.json externo
  • La aplicación utiliza la librería Paramiko para establecer conexiones SFTP seguras
  • Los errores se registran en el archivo error.log para facilitar el debugging
  • La configuración del servidor SFTP remoto (host, puerto, credenciales) debe definirse en config.json
  • Este endpoint está diseñado específicamente para servir archivos, no para operaciones CRUD completas

Controlador Asociado:

Archivo: app.py (Controlador Flask principal)

Método: Función de ruta dinámica que maneja el endpoint GET

Responsabilidades:

  • Procesar los parámetros de ruta compressed_file y filename
  • Establecer conexión SFTP con el servidor remoto
  • Buscar y descargar el archivo específico desde el archivo comprimido
  • Manejar errores de conexión y archivos no encontrados
  • Devolver el archivo como respuesta o mensajes de error apropiados

Configuración Requerida:

El archivo config.json debe contener la siguiente estructura:

{
    "sftp_host": "host.del.servidor.com",
    "sftp_port": 22,
    "sftp_username": "usuario",
    "sftp_password": "contraseña",
    "sftp_base_path": "/ruta/base/en/servidor"
}
