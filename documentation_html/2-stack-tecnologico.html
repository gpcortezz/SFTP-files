2.1. Tecnologías Principales:

  • Python: Lenguaje de programación principal
  • Flask: Framework web para la creación de la API REST
  • Paramiko: Biblioteca para conexiones SSH y SFTP
  • SFTP: Protocolo para transferencia segura de archivos

2.2. Dependencias Externas Clave:

  • Flask (framework web)
  • Paramiko (cliente SSH/SFTP)
  • Bibliotecas estándar de Python: JSON, Logging

2.3. Herramientas de Desarrollo Sugeridas:

  • Python 3.x
  • Editor de código (VS Code, PyCharm, etc.)
  • Git para control de versiones
  • Cliente SFTP para pruebas (FileZilla, WinSCP, etc.)
